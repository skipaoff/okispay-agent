# Агент «Оплата»

Агент для Claude. За 15–30 хвилин допомагає зробити власного Telegram-бота: бот показує покупниці твій продукт, приймає оплату (карткою через ФОП — у monobank або через WayForPay з рахунком у будь-якому банку, переказом на картку або в USDT) і сам відкриває доступ до закритого каналу.

## Як почати

1. Завантаж агента: зелена кнопка **Code** → **Download ZIP**, потім розпакуй архів.
2. Відкрий розпаковану папку в застосунку Claude, вкладка **Code**.
3. Напиши: «Допоможи налаштувати оплату».

Агент проведе по кожному кроку з картинками, сам перевірить токени, а наприкінці дасть пам'ятку: що по черзі надіслати боту налаштування оплат [@OkisPay_bot](https://t.me/OkisPay_bot).

## Що всередині
